Module Fs_spec_extras.Debug

module Debug: sig .. end
val start_timer : string -> float
start_timer s starts timing some operation described with string s. It prints a message and returns an object that should be passed to stop_timer, when the timing show stop.
val stop_timer : float -> string -> float
stop_timer t s stops timing of some operation described with string s. t is the result of a previous call to start_timer s. It prints the passed time in seconds and returns it as well.
val check_time : string -> ('a -> 'b) -> 'a -> 'b
check_time s f x is a wrapper around start_timer and stop_timer. It measures how long the execution of f x takes and returns the result pf f x. The string s is a description of the timed function used for printing messages.
